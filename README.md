# CopperWorks

Плагин для **Paper 26.3**: даёт медным големам профессии. Ванильный медный голем умеет только раскладывать вещи из медного сундука, а с CopperWorks он становится сортировщиком, курьером или фермером. Улучшения покупаются за медь.

## Как играть

1. Поставь медного голема рядом с **медным сундуком** (не дальше 2 блоков). Этот сундук станет его рабочим местом.
2. **Shift + ПКМ пустой рукой** по голему открывает меню: нативный диалог Minecraft, без GUI из сундуков.
3. Выбери профессию. Голем остаётся стоять у сундука и начинает работать.
4. Повторный Shift + ПКМ открывает панель управления: статус, окисление, улучшения, смена профессии, увольнение.

| Профессия | Что делает |
|---|---|
| **Сортировщик** | Раскладывает вещи из медного сундука по сундукам, бочкам и шалкерам вокруг. **Фильтр** задаётся рамкой с предметом, повешенной на сундук. Рамка с одним бревном принимает все брёвна: группы настраиваются в конфиге. Для предметов без фильтра работает как ваниль и кладёт их туда, где такие уже лежат. |
| **Курьер** | Забирает стаки из медного сундука и везёт их в выбранный контейнер **на любое расстояние**. В пути голем невидим, время рейса зависит от дистанции. Рейс продолжается через выгруженные чанки и рестарт сервера, потому что груз хранится в самом големе. Если контейнер назначения полон, курьер везёт остаток обратно. |
| **Фермер** | Собирает созревшие пшеницу, морковь, картофель, свёклу, адский нарост, какао, сладкие ягоды, а также тыквы и арбузы, выросшие от стебля. Пересаживает растения и складывает урожай в медный сундук. |

Профессии хорошо сочетаются: курьер может возить вещи в **медный сундук другого голема-сортировщика** на складе.

### Улучшения (0 → III)

- **Скорость**: +50% к темпу работы за уровень.
- **Вместимость**: больше предметов за перенос, стаков за рейс или растений за раз.
- **Дальность**: радиус сортировки и поля, у курьера максимальная дистанция (на III уровне без ограничений).

Цена по умолчанию: 16, 48 и 128 медных слитков. В креативе улучшения бесплатные.

### Окисление

Голем продолжает окисляться как в ванили, и окисленный работает медленнее (по умолчанию ×0.4). **Ось** снимает окисление, **соты** его консервируют. Нанятый голем никогда не превращается в статую, это можно отключить в конфиге.

## Команды и права

| Команда | Описание |
|---|---|
| `/cw` | Справка |
| `/cw list` | Сколько у тебя рабочих големов |
| `/cw reload` | Перезагрузить `config.yml` и `messages.yml` |

| Право | По умолчанию | Что даёт |
|---|---|---|
| `copperworks.use` | все | нанимать и управлять своими големами |
| `copperworks.unlimited` | op | без лимита големов на игрока |
| `copperworks.admin` | op | управлять чужими големами, `/cw reload` |

## Настройка

- `plugins/CopperWorks/config.yml`: лимиты, цены, скорости, радиусы, группы фильтров, защита.
- `plugins/CopperWorks/messages.yml`: все тексты в формате [MiniMessage](https://docs.advntr.dev/minimessage/format.html), их можно перевести или перекрасить.

## Сборка

Нужен JDK 25. Если его нет, Gradle скачает его сам через toolchains.

```bash
./gradlew build
```

Готовый плагин: `build/libs/CopperWorks-0.1.0.jar`. Положи его в папку `plugins/` сервера на Paper 26.3.

Тестовый сервер с плагином поднимается так:

```bash
./gradlew runServer
```

При первом запуске сервер остановится и попросит принять [Minecraft EULA](https://aka.ms/MinecraftEULA): поставь `eula=true` в `run/eula.txt` и запусти снова.

## Как это устроено

- **Нет базы данных.** Профессия, улучшения, точка доставки и груз курьера лежат в `PersistentDataContainer` самого голема. Отдельно хранится только `workers.yml`: кто сколько нанял, для лимита.
- **Ванильный ИИ нанятого голема выключен** (`setAware(false)`): голем стоит у сундука, поворачивается к цели и играет свои ванильные анимации «взял» и «положил». Предмет при этом летит по дуге (`ItemDisplay` с интерполяцией). Окисление продолжается, потому что оно тикает отдельно от ИИ.
- Голема можно увести **на поводке** к другому медному сундуку, и он сам переключится на новый пост.
- Фермер вызывает `EntityChangeBlockEvent`, поэтому плагины приватов могут запретить ему собирать чужой урожай. Точку доставки курьера нельзя выбрать в контейнере, к которому у игрока нет доступа.
- Нанятых големов по умолчанию может бить только владелец. `/kill` и пустота работают как обычно.
- Големы тикают, только пока их чанк загружен. Исключение одно: рейс курьера идёт по реальному времени.

## Важно

- Перед удалением плагина **увольняй големов**: у нанятых выключен ванильный ИИ, и без плагина они так и будут стоять.
- Folia не поддерживается.

## Что можно добавить дальше

- Големы, которые реально ходят по маршруту (через NMS-навигацию).
- Фильтр курьера: возить только то, что в рамках на медном сундуке.
- Профессия «шахтёр» или «пасечник», статистика в PlaceholderAPI, поддержка Folia.
